# Usage boundary
Offline hypothetical strategy simulation, pre-game training and post-game review only. No memory reading, packet interception, gameplay automation, client modification, live state monitoring or real-time prescriptive overlay. No official endorsement.
Riot public TFT documentation reviewed 2026-10-10: https://developer.riotgames.com/docs/tft (General Teamfight Tactics Policy). It encourages reflection/training and restricts dynamic real-time recommendations that prescribe in-game actions. Products serving players require registration. This local synthetic prototype has not been registered or approved; review requirements before external release.
JCC/Tencent policies and edition-specific data rights require independent verification; no assumption of Riot permissions transferring. Public accessibility does not establish scraping or redistribution rights. MetaTFT/DataTFT integrations require permission. Do not bypass access controls or explore private APIs.
No fabricated observed match statistics, samples, game strength or reforge probabilities. Estimates are visibly labeled. Synthetic examples never claim current patch validity. Human icon labels without image/version/canonical confirmation must not become training ground truth beyond the recorded label review.
