# CP-SAT and scoring
x[c] selects each unique available champion; y[c,e] equips one input emblem instance. Sum x equals board_size. Locks force x=1; bans, cost, unavailability and unknown unlock requirements force x=0. y<=x; illegal holders force y=0; each emblem is assigned to at most one selected unit (exactly one if unused forbidden); champion assignments cannot exceed item slots; duplicate equipment is capped by ruleset.
For each (c,t), contributor=max(native x, matching emblem assignments). Count is sum of contributors: logical OR prevents counting a natural trait twice, or duplicate emblems twice. Threshold b is equivalent to count>=b, using both reified directions. Active is first threshold. Cumulative utility uses incremental threshold differences, which sums to the highest reached utility.
Objective = active_count*A + breakpoint_utility*B + total_cost*C + equipped_count*D. Mode coefficients (A,B,C,D): MAX_ACTIVE_TRAITS (10000,10,-1,1); MAX_BREAKPOINT (10,100,-1,1); BALANCED (100,10,-2,5); LOW_COST (10000,1,-100,1); LATE_GAME (100,10,30,5). These guarantee priority only within the bounded fixture values; real catalogs must review scaling. LOW_COST favors active trait count then lower cost with minor breakpoint tie-breaks. LATE_GAME cost is a transparent heuristic. No win-rate data, ability score, formation score or item opportunity-cost estimate is invented.
After each candidate, sum(x[c] for c in previous board)<=board_size-min_champion_distance, applied against all prior candidates. With default distance 2, at least two champions are replaced. Emblem-only variations do not duplicate a board. CP-SAT shares a total request time budget; OPTIMAL is claimed only when solver proves it. Later candidate optima are conditional on prior exclusions; fewer than K is valid. enumeration_status states why enumeration stopped. Separate scoring layer recomputes components; separate rules independently validate extracted solutions.
Holder rank evaluates legal alternative placements on the best candidate with other assignments held fixed, sorting by additional activated traits then breakpoint utility. Skills/statistics remain null. It is not a global search of all joint holder alternatives.
Tests exhaust all 9-choose-7 boards with unused or legal single-emblem holders, comparing optimal objective to CP-SAT for every mode. Additional tests cover counting OR, multiple emblems, duplicates, slots, capacity, locks/bans/cost, nonlinear thresholds, isolation, infeasibility, timeout, diversity, missing stats and subsets.

Phase 4 reforge analysis enumerates the finite single-pass action tree independently of the board solver. Every distinct legal terminal inventory is optimized with unchanged CP-SAT constraints and objective. Verified rational path masses merge by terminal multiset; unknown masses stay null. Range, EV and downside gates and exhaustive reference tests are documented in REFORGE_ANALYSIS.md.
